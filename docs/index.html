Minecraft Server Management System

在自己的電腦上開伺服器，
然後讓它自己撐著。

一套裝在家用 Windows 機器上的管理工具。開伺服器不難，難的是它要一直開著—— 當掉要有人拉起來、世界要有人備份、朋友連不進來要查得出是哪一層壞了。這些是它處理的事。

Diagnostics

壞了的時候，先知道是哪一層壞

01本機服務伺服器程序本身活著嗎正常
02DNS網域指到正確的地方嗎正常
03隧道從這台打得到公開位址嗎失敗
04外部視角別人連得進來嗎失敗
05網頁地圖地圖站台回應嗎正常

六層由上往下排，因為下層的問題通常是上層造成的。上面這種狀況只有一個問題——隧道斷了—— 「外部視角」跟著紅只是結果。從最上面的失敗項開始查，就不會把時間花在追第二個症狀上。

What it does

它做什麼

01

讓外面連得進來

家用網路沒有固定 IP、開不了通訊埠。用 playit 隧道繞過，不必動路由器；有公網 IP 的話也可以直接轉埠。基岩版的朋友——手機、平板、主機——透過 Geyser 和 Floodgate 連進同一個伺服器，不需要 Java 帳號。

02

當掉了自己爬起來

看門狗每五分鐘檢查一次，伺服器意外死掉就重新啟動，並且分得出「你按了關閉」和「它自己掛了」。連續失敗會停手並留下紀錄，而不是無限重啟一個壞掉的東西。

03

備份不會壞掉存檔

先暫停自動存檔、把世界落盤、複製、壓縮，然後確認自動存檔真的恢復了——沒恢復就留下警告檔並通知。備份腳本讓存檔停在關閉狀態，是最容易發生又最難察覺的災難。

04

重啟前會先講

排程重啟在 5、3、1 分鐘各廣播一次，最後 30 秒開始倒數，存檔後才關。不會有人蓋到一半突然被踢下線。

05

在外面也能管

Discord 機器人可以查狀態、開關伺服器、下主控台指令，回覆只有你看得到。人不在電腦前也不用開遠端桌面。

06

一支程式裝完

安裝程式會抓 Paper、下載外掛、開啟 RCON、寫設定、註冊排程工作、建立防火牆規則。每一項都能個別取消勾選。

Requirements

需要什麼

作業系統Windows 10 或 11
Java21 以上（Paper 的要求）
記憶體建議 8 GB 以上，伺服器本身配 4 GB 綽綽有餘
網路一般家用寬頻即可。用 playit 的話不需要公網 IP
Python3.10 以上，只有手動安裝需要——安裝程式已內含

Limits

它不做什麼

這是為了自己家裡那台電腦寫的，不是通用的伺服器管理平台。用之前知道這些比較好：

  • 只支援 Windows腳本用了工作排程器、PowerShell 和 Windows 防火牆，沒有 Linux 或 macOS 版本。
  • 一次管一台伺服器沒有多實例、沒有多使用者、沒有權限分級。
  • 控制台只在內網它能執行任意主控台指令，所以刻意不對外開放。要在外面管理就用 Discord 機器人。
  • 介面是繁體中文程式碼註解和提交訊息是英文，但使用者看到的文字沒有英文版。
